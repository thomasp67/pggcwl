# Port Glasgow Golf Club (PGGC) — Winter Season Results Web App

A pure client-side static web application hosted on GitHub Pages that provides real-time scoring, competition management, handicap calculations, and tournament leaderboards for Port Glasgow Golf Club.

The application operates with **zero build tools** (no Node.js, Webpack, or npm required at runtime) and runs natively in any modern web browser. It supports both live web deployments (HTTP/HTTPS via GitHub Pages or local Apache) and fully offline local previews (`file://`).

### 1.1 Dual-Mode Data Architecture
1. **HTTP/HTTPS Mode (GitHub Pages / Local Web Server):**
   - On startup, `app.js` fetches `config/course.json`, `config/cuts.json`, `config/prizes.json`, `config/magic2s.json`, `config/lastman.json`, `config/tabs.json`, and `data/members.json`.
   - It then sequentially fetches `data/01.json`, `data/02.json`, ... up to `data/20.json`.
   - Discovery halts upon encountering the first HTTP 404. The highest loaded week is established as the latest active round.
   - All network requests include a timestamp query string (`?v=${Date.now()}`) and `cache: 'no-store'` to prevent stale browser caching.
2. **Offline Local File Mode (`file://`):**
   - When opened directly from disk without a web server, the browser's security model blocks standard `fetch()`.
   - The app seamlessly detects `window.location.protocol === 'file:'` and loads the pre-bundled `window.GOLF_DATA` from `data/data.js` (generated by `process_raw.php` / `process_raw.js`).

## 3. Mathematical & Scoring Calculation Engines

### 3.1 Playing Handicap Formula (World Handicap System)
Calculated dynamically for each player before every round based on their active Handicap Index ($HCI$) entering that week:
$$PlayingHandicap = \min\left(strokeLimit, \text{round}\left(allowance \times \left(HCI \times \frac{slopeRating}{113} + (courseRating - par)\right)\right)\right)$$
Since Port Glasgow Golf Club has $SR = 113$, $CR = 67.0$, $Par = 67$, and $Allowance = 1.0$:
$$PlayingHandicap = \min(36, \text{round}(HCI))$$

### 3.2 Hole Handicap Stroke Allocation
Strokes received by a player on a specific hole with Stroke Index $SI$:
$$HoleStrokes = \lfloor PlayingHandicap / 18 \rfloor + (PlayingHandicap \bmod 18 \ge SI \ ? \ 1 : 0)$$

### 3.3 Stableford Points per Hole
For hole gross score $G$:
- If $G \le 0$ (pickup, non-score, or uncompleted hole): $Points = 0$
- If $G > 0$:
$$Points = \max(0, HolePar + HoleStrokes - G + 2)$$
- **Total Points:** $\sum_{h=1}^{18} Points_h$

### 3.4 Countback Tiebreaker Cascade (Weekly Standings)
When multiple players tie on Stableford Total:
1. **Back 9:** Sum of points on Holes 10–18.
2. **Back 6:** Sum of points on Holes 13–18.
3. **Back 3:** Sum of points on Holes 16–18.
4. **Hole 18:** Points scored on Hole 18.
5. If completely tied across all countback stages, players share the tied rank (e.g. `T1`).

### 3.5 Scorecard Drawer & 0/NR Validation
When a user clicks on any player row in Weekend Stableford, Magic 2's, Player Profile, or Bingo:
- An inline drawer opens showing:
  - **Handicap Badges (Same Line):** `Current HCI: X` (entering index) • `Cut: Y` (adjustment earned) • `New HCI: Z` (updated index carrying forward).
  - **7-column card:** Par, Stroke Index, Strokes Received, Gross Score, Nett Score ($Nett = Gross - Strokes$), and Stableford Points.
  - **Gross 2 Highlights:** Any gross score of 2 is styled with an emerald/gold glow.
  - **No Return (NR) Rules:** A player must register a valid score on every hole to post a gross or nett total. If a player scores 0 on any hole of a nine, that nine's total displays **NR**.

## 4. Handicap Adjustment & Cut Engine (`config/cuts.json`)

All handicap cuts and increases accumulate chronologically across the 20 weeks. A player's active handicap entering Week $w$ is:
$$ActiveHCI_w = origHCI + \sum_{k=1}^{w-1} Cut_k$$
If a player does not play in Week $k$, $Cut_k = 0.0$ and their handicap carries forward unchanged.

```json
{
  "triggerPoints": 36,
  "bufferCapPoints": 43,
  "increasePoints": 30,
  "increaseAdjustment": 0.1,
  "tiers": [
    { "tier": 1, "minHci": 0.0,  "maxHci": 5.0,  "baseCut": 0.1, "cutPerPoint": 0.1, "capCut": -1.0 },
    { "tier": 2, "minHci": 5.1,  "maxHci": 10.0, "baseCut": 0.2, "cutPerPoint": 0.1, "capCut": -1.2 },
    { "tier": 3, "minHci": 10.1, "maxHci": 15.0, "baseCut": 0.3, "cutPerPoint": 0.1, "capCut": -1.4 },
    { "tier": 4, "minHci": 15.1, "maxHci": 20.0, "baseCut": 0.4, "cutPerPoint": 0.1, "capCut": -1.6 },
    { "tier": 5, "minHci": 20.1, "maxHci": 25.0, "baseCut": 0.5, "cutPerPoint": 0.1, "capCut": -1.8 },
    { "tier": 6, "minHci": 25.1, "maxHci": 99.9, "baseCut": 0.6, "cutPerPoint": 0.1, "capCut": -2.0 }
  ]
}
```

### 4.1 Adjustment Evaluation Rules
For a round with Stableford score $P$:
1. **Handicap Increase ($P < 30$):** $+0.1$ added to handicap index ($Adjustment = +0.1$, styled in **Blue**).
2. **Buffer Zone ($30 \le P < 36$):** No adjustment ($Adjustment = 0.0$, styled in **Neutral Grey**).
3. **Progressive Cut ($36 \le P < 43$):**
   - Active tier determined by player's active $HCI$:
     $$Cut = -1 \times \left(baseCut + (P - 36) \times cutPerPoint\right)$$
   - Capped at the tier's $capCut$.
4. **Buffer Cap Cut ($P \ge 43$):** Player receives the full tier maximum cut:
   $$Cut = capCut$$
5. **Red Cut Highlighting:** Wherever a cut has been applied (e.g. `-0.4`, `-1.2`), it is prominently highlighted in **Red** (`#b91c1c` text, `#fee2e2` background, `#fca5a5` border) across Weekend Stableford, the drawer badges, Winter League leaderboard, Handicap List matrix, and Player Profile.

## 5. Prize Money & Competition Configurations (`config/prizes.json`)

The prize funds are driven by `config/prizes.json`:

```json
{
  "sweep": {
    "entryFee": 2.00,
    "description": "Weekend Stableford Sweep prize fund (£2 per entrant)",
    "tiers": [
      { "minEntrants": 16, "shares": [0.50, 0.30, 0.20], "description": "16+ players: 1st 50%, 2nd 30%, 3rd 20%" },
      { "minEntrants": 10, "shares": [0.65, 0.35], "description": "10-15 players: 1st 65%, 2nd 35%" }
    ]
  },
  "magic2s": {
    "entryFee": 1.00,
    "eligibility": "league_only",
    "description": "Magic 2's competition: £1 entry fee per entrant. League prize pot is league entrants x £1."
  }
}
```

### 5.1 Weekend Sweep Prize Pot Rules
- **Entry Fee:** £2.00 per entrant (open to all club entrants).
- **Total Pot:** $FieldSize \times £2.00$.
- **Payout Brackets:**
  - **$\ge 16$ entrants:** 1st 50%, 2nd 30%, 3rd 20%.
  - **10–15 entrants:** 1st 65%, 2nd 35%.
  - **$< 10$ entrants:** 1st 100%.
- **Tied Payouts:** Tied players combine the prize shares for their tied positions and divide equally.

### 5.2 Magic 2's Prize Pot & Rollover Rules
- **Entry Fee:** £1.00 per entrant.
- **Weekly League Prize Pot:** $LeagueEntrants \times £1.00 + RolloverFromPreviousWeek$.
- **Winner Eligibility:** **Only Winter League members** (`inLeague: true`) can win shares of the prize pot.
- **Rollover Rule:** If no eligible gross 2s are scored by league members in a week, the **entire Weekly Prize Pot rolls over** to the following week.

## 6. The Seven Competition Views

### View 1: Weekend Stableford (`#tab-weekly`)
- **Eligibility:** Open to all club members.
- **Dynamic 3-Way League Filter:** Cycles on click:
  1. **All Players (Default):** Checkbox unchecked, displays all sweep entrants.
  2. **League Only (1st Click):** Checkbox checked, displays only league members.
  3. **Non-League Only (2nd Click):** Checkbox in indeterminate/dash state, displays guests and non-league players.
  4. **Cycle back to All (3rd Click):** Reverts to showing all entrants.
- **Gross Scores Toggle:** Checkbox toggles hole columns between Stableford points and Gross scores.
- **Scorecard Drawer Badges:** On row expansion, shows `Current HCI`, `Cut` (red if cut applied), `New HCI`, and `Day` (Saturday/Sunday badge) on the same line.
- **Info Bar:** Displays responsive dynamic summary:
  - Desktop: Line 1 format • Line 2: Entrants • Sweep Pot • 1st, 2nd, 3rd prizes.
  - Mobile: Single continuous line separated by `•`.

### View 2: Winter League (`#tab-leaderboard`)
- **Eligibility:** Winter League members only (`inLeague === true`).
- **Season Metric:** Ranked by the sum of each player's **Best 10 Stableford scores**.
- **Score Heatmap:** 1–10 counting scores display in an intuitive color-coded heatmap (from deep emerald $\ge 40$ pts to coral-red $< 24$ pts).
- **Interactive Sorting:** Clickable headers toggle sorting for Pos, Total Cut, Rounds, Average, Money Won, and Total.
- **Rank Movement Indicator:** Displays week-over-week leaderboard movement (`▲N` / `▼N`).
- **Info Bar:** Displays `Season Long League • Best 10 Stableford Scores Count` and `{X} played this week`.

### View 3: Magic 2's (`#tab-magic2s`)
- **Objective:** Gross 2 on 3 randomly drawn Par 3 holes (or any Par 4 / Par 5).
- **Draw Schedule (`config/magic2s.json`):** 20 combinations of 3 holes selected from the 6 Par 3s.
- **All 2's Table:** Displays all players who scored any 2 with drawn Par 3 indicators and rollover entries when no winner occurred.
- **Non-Qualifying 2s:** Struck-through with `£0.00` badge and clear explanatory label.

### View 4: Last Man Standing (`#tab-lastman`)
- **Survival Mechanics:** Sudden-death hole-by-hole knockout competition.
- **Eliminated Format:** When eliminated, player status displays `(Wk 1 💀)` (or whichever week they were eliminated in).
- **Mobile Options:** Configurable admin toggles allow hiding the summary info card and status dropdown filter on mobile screens.

### View 5: Eclectic Competition (`#tab-eclectic`)
- **Metric:** Compiles each player's **personal best Stableford score on each of the 18 holes** across all rounds played.
- **Winner Dropdown:** Toggles between **Nett** ($Points - Strokes$) and **Points** (Gross Stableford Total).

### View 6: Bingo (`#tab-parbingo`)
- **Objective:** First player to register a qualifying score on all 18 holes of the course wins Bingo.
- **Dual Modes:** **Gross Pars** ($gross \le par$) or **Net Birdies** ($nett \le par - 1$ or $\ge 3$ pts).

### View 7: Player Profile & Handicap List (`#tab-player`)
- **Player Details:** Autocomplete search, quick-picks, KPI stats, and complete weekly scoring history.
- **Handicap List:** Full 20-week matrix tracking weekly handicap adjustments and active indexes for every member.

## 7. Dynamic Information Templates (`config/tabs.json`)

The header subtitle bar for each tab is fully configurable in `config/tabs.json` and evaluates dynamic tokens at runtime:

- `{Number of Entrants}`: e.g. "23 Entrants" (or "23" when preceding "Entrants")
- `{£x}` or `{x}`: e.g. "£46.00"
- `{1st Prize}`, `{2nd Prize}`, `{3rd Prize}`: Evaluates sweep prize pot shares
- `{Number of players in the active week}`: e.g. "23 played this week"
- `{Prize Pot}`: e.g. "Prize Pot: £46.00"
- `{weeks active hole}`: Evaluates the active knockout target hole for the week
- `{16 of 49}`: Evaluates `${aliveCount} of ${totalCount}` players still standing

**Responsive Formatting:** Multi-line text separated by `\n` renders as separate lines on desktop screens and effortlessly combines into a single line separated by `•` on mobile devices.

## 9. Winter League Cup (Concept Feature — Accessed via `/cup`)

A dedicated matchplay tournament concept designed for the Winter League members.

### Access & Hidden Navigation:
- **Zero-Display on Main Site:** The Cup tab is hidden from public desktop tab buttons and mobile dropdowns (`hideDesktop: true`, `hideMobile: true` in `config/tabs.json`).
- **Secret URL Route:** Accessible directly via **`/cup`** in the browser (e.g. `http://localhost/pggcwl/cup`, `http://localhost/pggcwl/index.html#cup`, or `?tab=cup`).
- **Concept Mode Banner:** Displays an amber preview banner with a quick "← Main Site" exit button to return to the public dashboard.

### Rules & Tournament Mechanics:
1. **Field Selection & Pots:**
   - 49 registered Winter League members.
   - Top 48 players by starting Handicap Index ($HCI$) are seeded into **4 Pots of 12** (Seeds 1 to 12 within each pot).
   - Player #49 (**Dylan Leonard**, $HCI\ 32.4$) is designated as the official 1st Reserve.
2. **11-Week Round-Robin (Group Phase):**
   - In each pot, players pair off each week using the **Berger circle algorithm** ($1\text{v}12, 2\text{v}11, 3\text{v}10, 4\text{v}9, 5\text{v}8, 6\text{v}7$ in Week 1).
   - Every player plays every other player in their pot exactly once over the 11 weeks.
3. **Scoring & Differential:**
   - Evaluated on weekly Stableford points.
   - **Win:** 3 points | **Draw:** 1 point | **Loss:** 0 points.
   - **Differential (Diff):** $PointsFor - PointsAgainst$ tracked and accumulated across all matches.
4. **Single Unified Table (48 Players):**
   - Results from all 4 pots feed into a single overall 48-player league table.
   - Sorted by: $CupPoints \rightarrow Diff \rightarrow PointsFor \rightarrow PointsAgainst \rightarrow origHCI$.
5. **Top 16 Knockout Phase (Weeks 12–15):**
   - The top 16 players from the unified table advance to a single-elimination knockout tournament:
     - **Round of 16 (Week 12):** $1\text{v}16, 8\text{v}9, 4\text{v}13, 5\text{v}12, 2\text{v}15, 7\text{v}10, 3\text{v}14, 6\text{v}11$.
     - **Quarter-Finals (Week 13):** 8 winners.
     - **Semi-Finals (Week 14):** 4 winners.
     - **Final (Week 15):** 2 finalists compete for the Cup Championship 🏆.
